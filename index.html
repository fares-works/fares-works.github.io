Moasher — IoC Management & Threat Hunting Dashboards

Moasher is a security platform built around Indicators of Compromise (IoCs): a lab environment populated with IoCs, a website to run scans and see whether IoCs are present and how severe they are, and a database that stores every result.

I built the Power BI layer that turns those scan results into answers: an Overview page for daily change, IoC distribution by IP and source, and drill-downs by target OS, scanner and rule, plus a Threat Hunting Hub page with headline KPIs, high-severity counts and trends over time.
